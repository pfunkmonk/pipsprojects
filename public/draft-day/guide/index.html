Before auction day

Set up once.
Rehearse once.

1. Create the league

Enter the league name, season, teams, nomination order, roster size, bid rules, and position requirements. Leave a position maximum blank when backups are unrestricted at that position. Allow any mix of backups clears every position maximum at once; the overall roster maximum still applies.

2. Enter starting pools

Enter each team's salary pool before keepers. Keeper salaries always deduct automatically, so a $5 keeper from a $100 starting pool leaves $95 available at auction. Use Apply default pool to every team when the pools match.

3. Set keeper rules

Maximum keepers per team is optional. Leave it blank to use the overall roster maximum. Keepers themselves are recorded later by the auctioneer, where the budget and legal-roster checks run immediately.

4. Save the access sheet

The organizer, auctioneer, and Draft Board receive separate codes. Download the access JSON when the league is created; plaintext access codes are not displayed again after leaving that result screen.

Keeper entry

Record, check, and lock keepers

  1. Open the Auctioneer Tool and use the large Keeper Setup control to expand or collapse the section.
  2. Search the 2026 player pool; position, NFL team, and bye week fill automatically. Use Add missing player manually only when the player is not in the pool.
  3. Select the fantasy team and enter salary. Contract year and keeper round are optional.
  4. Confirm the before-and-after cash preview, then record the keeper.
  5. Review every team's keeper count, keeper spend, remaining cash, and roster progress.
  6. Click Lock keepers when entry is complete. You can unlock it until the first auction sale.

The first auction sale permanently locks new keeper entry. Existing keepers can still be corrected, undone, or restored when the repaired league state remains legal.

In the room

Auctioneer workflow

  1. Search and select the nominated player. The Draft Board immediately shows a large position-colored nomination card with NFL team and bye week.
  2. Select the winning fantasy team and enter the price.
  3. Read the cash-before, price, cash-after, and legal-maximum preview. Illegal bids and impossible roster paths cannot be recorded.
  4. Record the sale. The nomination card disappears, team cash and roster update, and the next nominator advances automatically when tracking is enabled.
  5. Use Correct, Undo, or Restore in Assignment History when the room calls out a mistake.
  6. Optionally enable the local nomination clock. A recorded sale restarts it for the next nomination.
  7. Use Finish draft only after every team meets its legal roster minimum. The draft can be reopened.
  8. Export the spreadsheet-safe results CSV and a complete JSON backup.

Keyboard shortcuts: Ctrl/⌘ K moves to player search. Ctrl/⌘ Z undoes the latest active auction sale.

Projection screen

Draft Board workflow

Open the board on the projector or a second device and sign in with the read-only Draft Board code. Use Fullscreen for the room display. Every player sticker shows position color, NFL team, bye week, and price. Keepers are pinned first and carry a gold KEEPER tag. The board contains public auction facts only—never rankings, event history, setup-only pool data, or draft advice.

Refresh and access

Refresh stays signed in. Logout does not.

An ordinary browser refresh or restart returns to the same Organizer, Auctioneer, or Draft Board screen without another code entry. Access is stored in a signed, persistent browser cookie and is renewed when the role session is checked. Use Log out only when you intentionally want to clear all Draft Day roles on that browser and require an access code next time. If the server rejects a cookie after a security-secret change, the Auctioneer's pending action remains on that device and syncs after authentication.

Safety

If the connection drops

The signed-in Auctioneer device keeps a local snapshot and queues pending actions. A board open in the same browser receives local updates; separate devices catch up when the connection returns. Watch the Auctioneer status until it returns to LIVE. Use Backup JSON during breaks and Export results CSV at the end. If the app explicitly asks for sign-in again, re-enter the role code rather than refreshing repeatedly.
