Before auction day

Set up once.
Rehearse once.

1. Create the league

Enter the league name, teams, pools, roster rules, and optional keeper maximum. The league code is the first eight letters or numbers of its name. Add a position maximum only when the league has a specific cap; otherwise leave it blank.

2. Choose the pool mode

Current auction cash means keeper costs have already been removed. Starting pool means the tool deducts keeper salaries for you.

3. Record keepers

Open the auctioneer console, expand Keeper Setup, search the 2026 player pool, and record each fantasy team, salary, optional contract year, and optional keeper round. Keepers immediately occupy roster and position slots and appear pinned on the public board.

4. Save the access sheet

The organizer, auctioneer, and Draft Board receive separate codes. Download the access JSON when the league is created; codes are not shown later.

In the room

Auctioneer workflow

  1. Sign in with the league code and auctioneer code.
  2. Finish Keeper Setup before the first auction sale.
  3. Search and select the nominated player.
  4. Select the winning team and enter the price.
  5. Confirm the cash impact and record the sale.
  6. Use Correct or Undo immediately if the room calls out a mistake.
  7. Export results CSV and a JSON backup when the auction finishes.

The first sale locks new keeper entry. Audited keeper corrections remain available when the repaired league state is legal. A sale is blocked when it would exceed cash, roster limits, or the money required to complete a legal minimum roster.

Projection screen

Draft Board workflow

Open the board on the projector or a second device and sign in with the read-only Draft Board code. Use Fullscreen for the room display. Every player sticker shows the position color, NFL team name, bye week, and price. Keepers are pinned first and carry a gold KEEPER tag. The board contains public auction facts only—never rankings or draft advice.

Safety

If the connection drops

The auctioneer keeps a local snapshot and queues pending actions on the signed-in device. A board open on the same device receives local updates. Separate devices catch up after the connection returns. Use Backup JSON during breaks and Export CSV when the draft ends.
