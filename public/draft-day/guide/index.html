Before auction day

Set up once.
Rehearse once.

1. Create the league

Enter the league name, number of teams, minimum bid, roster minimum and maximum, and each position's minimum and maximum.

2. Choose the pool mode

Current auction cash means keeper costs have already been removed. Starting pool means the tool deducts keeper salaries for you.

3. Add teams and keepers

Enter the actual auction-day pool for each team. Keepers immediately occupy roster and position slots and appear pinned on the public board.

4. Save the access sheet

The organizer, auctioneer, and Draft Board receive separate codes. Download the access JSON when the league is created; codes are not shown later.

In the room

Auctioneer workflow

  1. Sign in with the league code and auctioneer code.
  2. Search and select the player.
  3. Select the winning team and enter the price.
  4. Confirm the cash impact and record the sale.
  5. Use Correct or Undo immediately if the room calls out a mistake.

A sale is blocked when it would exceed the team's cash, roster maximum, position maximum, or the money required to complete a legal minimum roster.

Projection screen

Draft Board workflow

Open the board on the projector or a second device and sign in with the read-only Draft Board code. Use Fullscreen for the room display. The board contains only team names, player assignments, prices, cash, and roster counts.

Safety

If the connection drops

The auctioneer keeps a local snapshot and queues pending actions on the signed-in device. A board open on the same device receives local updates. Separate devices catch up after the connection returns. Use Backup JSON during breaks and Export CSV when the draft ends.
